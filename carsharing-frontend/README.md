# Carsharing Frontend (DRIVEOUT)

Next.js (App Router) фронтенд, реалізує розділ 6-7 плану: головна, каталог з фільтрами, сторінка авто з бронюванням, кабінет, авторизація.

## Запуск

```bash
npm install
cp .env.local.example .env.local
# переконайтесь, що NEXT_PUBLIC_API_URL вказує на запущений backend (http://localhost:5000/api)

npm run dev
```

Відкрити `http://localhost:3000`. Бекенд (`carsharing-backend`) має бути запущений і мати заповнену БД (`npm run prisma:seed`), інакше каталог буде порожній.

## Реалізовані сторінки

| Маршрут | Опис |
|---|---|
| `/` | Головна: hero, популярні авто, "як це працює" |
| `/cars` | Каталог з фільтрами (бренд, ціна, коробка, паливо, місця) |
| `/cars/[id]` | Деталі авто, характеристики, відгуки, форма бронювання |
| `/login`, `/register` | Авторизація (JWT зберігається в localStorage) |
| `/profile` | Активні бронювання, оплата, скасування, історія оренд |

## Дизайн-система
Токени та компоненти — у `src/app/globals.css`. Палітра: графіт + сигнальний бурштиновий акцент, шрифти Barlow Condensed (заголовки/дані) + Inter (текст) + IBM Plex Mono (ціни/лейбли).

## Що далі за планом
1. Адмін-панель (`/admin`) — CRUD авто, керування бронюваннями, статистика (API вже готове: `/api/admin/*`)
2. Сторінка створення відгуку після завершеної оренди
3. Валідація форм на клієнті (наразі базова — через `required`/`minLength`)
4. next/image замість `<img>` для оптимізації зображень авто
