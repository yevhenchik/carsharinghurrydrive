# Carsharing Frontend

Фронтенд на Next.js (App Router) до сайту оренди авто — той самий навчальний проєкт, що й бекенд, разом вони й утворюють HurryDrive.

## Запуск

```bash
npm install
cp .env.local.example .env.local
```

У `.env.local` треба вказати адресу бекенда, наприклад:
```
NEXT_PUBLIC_API_URL=http://localhost:5050/api
```
(порт має збігатись з тим, на якому реально піднятий бекенд)

```bash
npm run dev
```

Відкрити `http://localhost:3000`. Бекенд має бути вже запущений і з заповненою базою (`npm run prisma:seed`), інакше каталог авто буде порожній.

Node потрібен 18.17+ (у мене працює через nvm, `nvm use 20`).

## Сторінки

| Маршрут | Що там |
|---|---|
| `/` | Головна — банер, інтерактивна карта міст де є сервіс, популярні авто |
| `/cars` | Каталог з фільтрами: місто, бренд/модель (пошук за початком слова), ціна, коробка передач, паливо, кількість місць |
| `/cars/[id]` | Сторінка авто — характеристики, бронювання з розрахунком вартості, відгуки + форма щоб залишити свій |
| `/login`, `/register` | Авторизація, токен зберігається в localStorage |
| `/profile` | Активні бронювання (оплата/скасування) і історія оренд |
| `/admin` | Тільки для ролі ADMIN — статистика, керування автопарком, перегляд і видалення бронювань |

## Дизайн

Все кольори/шрифти в `src/app/globals.css` через CSS-змінні. Темна графітова тема + бурштиновий акцент, заголовки Barlow Condensed, текст Inter, ціни/лейбли IBM Plex Mono. Карта міст на головній — це власний SVG, координати міст порахував по реальних широті/довготі, не готова бібліотека.

## Структура

- `src/app` — сторінки (App Router)
- `src/components` — Header, Footer, CarCard, GermanyMap, HeroActions
- `src/lib` — `api.js` (обгортка над fetch до бекенду), `auth.js` (контекст авторизації), `cities.js` (список міст)
